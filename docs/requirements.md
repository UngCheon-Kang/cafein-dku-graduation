# 요구분석명세서

CAFEIN의 기능 요구사항을 화면 영역별로 정리한 문서입니다. 기획 단계에서 작성했으며, 구현은 이 명세를 기준으로 진행했습니다.

| 영역 | 기능 수 |
|---|---:|
| 홈 | 14 |
| 지도 | 7 |
| 커뮤니티 | 24 |
| 채팅 | 9 |
| 마이페이지 | 11 |
| 계정 | 11 |
| 관리자 | 6 |
| **합계** | **82** |

## 홈

**RQ_HOME_01 · 카페 탐색**

| 기능 ID | 기능명 | 상세 설명 |
|---|---|---|
| `RQ_HOME01_LIST01` | 카페 검색 | 카페명 또는 동네명으로 카페를 검색 |
| `RQ_HOME01_LIST02` | 카페 목록 정렬 | 추천순 / 거리순으로 카페 목록을 정렬 |
| `RQ_HOME01_LIST03` | 카페 목록 조회 | 카페 사진과 별점(카공지수)를 포함한 카페 목록을 조회 (임시) |

**RQ_HOME_02 · 카페 상세 정보**

| 기능 ID | 기능명 | 상세 설명 |
|---|---|---|
| `RQ_HOME02_DETAIL01` | 카페 기본 정보 조회 | 카페 사진, 위치, 영업 시간을 조회 |
| `RQ_HOME02_DETAIL02` | 카공 지수 표시 | 콘센트, 와이파이, 좌석, 소음 4개 지표와 이를 평균을 낸 종합 카공 지수를 표시 (임시) |
| `RQ_HOME02_DETAIL03` | 리뷰 미리보기 | 기본 정보 화면 하단에 리뷰 일부(상위 몇개)를 노출 |
| `RQ_HOME03_REVIEW02` | 리뷰 작성 | 카공지수 4지표를 선택하여 텍스트, 사진을 포함한 리뷰를 등록 |

**RQ_HOME_03 · 리뷰 조회**
