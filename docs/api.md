# API 설계

CAFEIN 백엔드는 **REST API 88개 엔드포인트**와 WebSocket(STOMP) 채널로 구성됩니다.
도메인별로 컨트롤러를 분리했고, 인증 정책은 경로 단위로 세 단계로 나눴습니다.

> 엔드포인트 상세 명세는 운영 중인 서비스 보호를 위해 공개하지 않습니다.
> springdoc(OpenAPI)로 Swagger UI를 제공하며, 개발 환경에서만 노출합니다.

---

## 1. 도메인 구성

| 영역 | 엔드포인트 | 주요 내용 |
|---|---:|---|
| 계정 · 인증 | 25 | 이메일 가입/인증, 소셜 로그인 3종, 토큰 재발급, 비밀번호 재설정, 프로필 관리 |
| 관리자 | 21 | 신고 처리, 콘텐츠 숨김, 이용 정지, 카페·이미지 관리 |
| 카페 | 6 | 목록·상세·검색, 북마크 |
| 커뮤니티 (피드) | 6 | 작성·수정·삭제·검색, 조회수 |
| 댓글 | 5 | 댓글·대댓글 |
| 스터디 모집 | 5 | 신청, 수락·거절, 신청자 조회 |
| 채팅방 | 5 | 방 생성·목록·메시지 조회·읽음 처리 |
| 알림 | 5 | 목록, 안 읽은 수, 읽음·삭제 |
| 차단 | 3 | 차단·해제·목록 |
| 리뷰 | 3 | 작성·수정·삭제 |
| 좋아요 | 2 | 등록·취소 |
| 이미지 | 1 | S3 presigned URL 발급 |
| 신고 | 1 | 신고 접수 |

실시간 채팅은 별도로 **STOMP over WebSocket** 채널(`/ws`)을 사용합니다.

## 2. 인증 정책

Spring Security 필터 체인에서 경로 단위로 분리했습니다.

| 구분 | 대상 | 예시 |
|---|---|---|
| 공개 | 인증 전에 필요한 기능, 콘텐츠 조회 | 가입·로그인·토큰 재발급, 중복 확인, 카페·피드 **조회(GET)** |
| 로그인 필요 | 작성·수정·삭제 등 나머지 전부 | 리뷰·글·댓글 작성, 채팅, 알림, 마이페이지 |
| 관리자 | `/admin/**` 전체 | 신고 처리, 이용 정지, 콘텐츠 숨김 |

- 인증은 **JWT access / refresh 토큰 분리** 방식입니다.
- 로그아웃한 access 토큰은 Redis 블랙리스트에 등록해 만료 전에도 차단합니다.
- 소셜 로그인은 각 제공자의 토큰을 **서버에서 검증**한 뒤 자체 JWT를 발급합니다.

## 3. 설계에서 신경 쓴 점

**권한 검사는 서버에서**
관리자 화면은 별도 웹으로 분리했지만, 접근 제어는 화면이 아니라 **API 레벨에서** 수행합니다.
`/admin/**`은 `ROLE_ADMIN`을 요구하므로 클라이언트를 우회해도 접근할 수 없습니다.

**소유자 검증**
수정·삭제 API는 요청자와 리소스 소유자를 비교합니다.
타인의 리뷰·글·댓글은 ID를 알아도 변경할 수 없습니다.

**요청 수 제한 (Redis)**
무차별 시도와 스팸을 막기 위해 민감한 동작에 제한을 뒀습니다.

| 대상 | 제한 |
|---|---|
| 로그인 | 계정당 5회 실패 시 15분 차단 |
| 인증코드 재발송 | 60초 쿨다운, 최대 5회 |
| 인증코드 검증 | 5회 초과 시 가입 요청 폐기 |
| 채팅 전송 | 사용자당 10초에 10건 |

로그인 실패 시 "이메일이 없는지, 비밀번호가 틀렸는지"를 구분하지 않는 동일한 메시지를 반환해
계정 존재 여부가 드러나지 않도록 했습니다.

**이미지 업로드**
서버는 이미지 바이트를 다루지 않고 **presigned URL만 발급**합니다.
발급 시 업로드 대상 폴더와 확장자를 서버에서 검증해, 허용되지 않은 경로에는 올릴 수 없습니다.

**페이지네이션**
목록 응답은 Spring `Slice`를 사용합니다. 전체 개수를 세지 않아 count 쿼리가 발생하지 않습니다.

```json
{ "content": [ ... ], "number": 0, "size": 20, "first": true, "last": false }
```

## 4. 오류 응답

```json
{ "status": 409, "message": "이미 사용중인 이메일입니다." }
```

| 코드 | 상황 |
|---|---|
| 400 | 입력값 오류 |
| 401 | 인증 필요 또는 토큰 만료 |
| 403 | 권한 없음 (타인의 리소스, 정지·탈퇴 계정) |
| 404 | 대상 없음 |
| 409 | 중복 (이메일·닉네임·리뷰 중복 작성) |
| 429 | 요청 제한 초과 |

예외는 전역 핸들러에서 처리하며, 운영 환경에서는 스택 트레이스를 응답에 포함하지 않습니다.
