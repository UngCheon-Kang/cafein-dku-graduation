# 화면별 기능 확인서

각 화면의 구성과 동작, 화면 간 이동, 필요한 데이터를 정리한 문서입니다. 요구분석명세서와 함께 구현의 기준으로 사용했습니다.

| 영역 | 화면 수 |
|---|---:|
| 홈 | 4 |
| 지도 | 3 |
| 커뮤니티 | 13 |
| 채팅 | 2 |
| 마이페이지 | 7 |
| 계정 | 8 |
| 관리자 | 4 |
| **합계** | **41** |

---

## 홈

### 카페상세

대표 사진 띄움. 뒤로가기·피드작성(연필)·북마크 버튼 사용. 카페명·평점 표시. 주소·영업시간(영업중 여부) 표시. 카공지수 표시(콘센트/와이파이/소음/좌석 각 상태). 리뷰 미리보기 띄움(전체 보기 이동). 리뷰 작성 버튼.

- **연결 화면** — 카페 리뷰 전체, 리뷰 작성, 피드 작성
- **필요 데이터** — 카페 상세(이름, 사진, 평점, 주소, 영업시간, 카공속성), 리뷰 미리보기, 북마크 여부

### 리뷰작성

대상 카페명 표시. 카공지수 평가함(콘센트/와이파이/소음/좌석 각 3단계 선택). 후기 내용 입력함(최대 500자). 사진 첨부함(0/5). 등록하기 버튼.

- **연결 화면** — 카페 상세
- **필요 데이터** — 카페ID, 작성자ID, 콘센트·와이파이·소음·좌석 평가, 내용, 사진

### 카페리뷰 전체

리뷰 총 개수 표시. 정렬 드롭다운 사용(최신순). 리뷰 목록 띄움(작성자 프로필·닉네임·시간, 카공지수 태그, 내용, 사진). 내가 쓴 리뷰는 수정·삭제 버튼 표시. 리뷰 작성 버튼.

- **연결 화면** — 리뷰 작성, 사용자 상세
- **필요 데이터** — 리뷰 목록(작성자, 시간, 카공지수, 내용, 사진), 정렬기준

### 카페목록

카페 또는 동네 검색바 띄움.정렬 토글 사용(추천순/거리순). 카페 카드 목록 띄움. 카드에 썸네일·카페명·평점·위치·리뷰수 표시. 카드 누르면 카페 상세로 이동.

- **연결 화면** — 카페 상세, 검색
- **필요 데이터** — 카페 목록(카페ID, 이름, 썸네일, 평점, 위치, 리뷰수), 정렬기준, 검색어

## 지도

### 지도 메인

지도 띄움(현재 위치 기준). 카페 위치마다 마커 표시. 상단 검색바 사용(카페/동네 검색). 조건 필터 칩 사용(콘센트/와이파이/소음/좌석). 내 위치로 이동 버튼. "이 지역 재검색" 버튼(지도 이동 후). 마커 누르면 하단에 카페 미리보기 카드 띄움.

- **연결 화면** — 카페 미리보기, 필터
- **필요 데이터** — 카페 목록(카페ID, 이름, 위치 좌표, 평점, 카공속성), 현재 위치, 필터 조건, 지도 범위

### 카페 미리보기

카페 썸네일·이름·평점 표시. 위치(거리) 표시. 누르면 카페 상세로 이동.

- **연결 화면** — 카페 상세
- **필요 데이터** — 카페 요약(이름, 썸네일, 평점, 거리)

### 필터

콘센트 조건 선택함(예: 넉넉/보통 이상). 와이파이 조건 선택함. 소음 조건 선택함. 좌석 조건 선택함. 평점·영업중 같은 추가 조건(선택). 초기화 버튼. 적용 버튼(결과 개수 표시).

- **연결 화면** — 지도 메인
- **필요 데이터** — 콘센트·와이파이·소음·좌석 필터 조건

## 커뮤니티

### 피드목록

검색바 띄움. 타입 탭 사용(전체/자유/카페추천/스터디모집). 정렬 드롭다운 사용(최신순/인기순). 피드 미니카드 목록 띄움. 카드에 작성자·작성시간·타입·썸네일·좋아요수·댓글수 표시. 피드 작성 플로팅 버튼(연필) 띄움. 카드 누르면 피드 상세로 이동.

- **연결 화면** — 피드 상세, 피드 작성-유형선택, 검색
- **필요 데이터** — 피드 목록(피드ID, 작성자 닉네임, 썸네일, 작성시간, 타입, 좋아요수, 댓글수), 정렬기준, 선택 타입

### 피드작성-유형선택

자유/카페추천/스터디모집 중 유형 선택함. 선택한 유형에 따라 다음 작성 화면 입력 항목 달라짐.

- **연결 화면** — 피드 작성-내용입력
- **필요 데이터** — 피드유형

### 피드작성-자유

제목 입력함. 내용 입력함. 사진 첨부함(최대 5장, 삭제 가능). 등록 버튼.

- **연결 화면** — 피드 상세
- **필요 데이터** — 작성자ID, 피드유형(자유), 제목, 내용, 사진

### 피드작성-카페추천

제목 입력함. 내용 입력함. 사진 첨부함(최대 5장). 카페 선택함(검색해서 태그, 홈에서 진입 시 자동 태그). 등록 버튼.

- **연결 화면** — 피드 상세, 카페 검색
- **필요 데이터** — 작성자ID, 피드유형(카페추천), 제목, 내용, 사진, 카페ID

### 피드작성-스터디모집

제목 입력함. 내용 입력함. 사진 첨부함(최대 5장). 장소 입력함. 일시 선택함(날짜·시간). 모집인원 입력함. 등록 버튼.

- **연결 화면** — 피드 상세
- **필요 데이터** — 작성자ID, 피드유형(스터디모집), 제목, 내용, 사진, 장소, 일시, 모집인원

### 피드상세-자유

작성자 프로필·닉네임·작성시간 띄움. 사진·제목·내용 띄움. 좋아요 버튼·좋아요수 표시. 댓글·대댓글 목록 띄움·작성함. 더보기(...) 수정·삭제(본인)/신고(타인). 작성자·댓글작성자 누르면 프로필 이동.

- **연결 화면** — 사용자 상세, 피드 작성(수정)
- **필요 데이터** — 피드 상세(피드ID, 작성자, 시간, 제목, 내용, 사진, 좋아요수), 댓글 목록

### 피드상세-카페추천

(자유 상세 공통) + 카페정보 블록 띄움(카페명·주소·영업시간·카공속성·평점). 카페정보 누르면 카페 상세로 이동.

- **연결 화면** — 사용자 상세, 카페 상세, 피드 작성(수정)
- **필요 데이터** — 피드 상세 + 카페정보(카페ID, 이름, 주소, 영업시간, 카공속성, 평점), 댓글 목록

### 피드상세-스터디모집

(자유 상세 공통) + 모집정보 블록 띄움(장소·일시·모집인원·모집상태). 신청하기 버튼. 모집현황 표시(현재/정원). 마감 시 버튼 비활성·"마감" 표시.

- **연결 화면** — 연결화면: 사용자 상세, 피드 작성(수정)
- **필요 데이터** — 필요 데이터: 피드 상세 + 모집정보(장소, 일시, 모집인원, 현재인원, 모집상태), 댓글 목록

### 검색

검색바에 검색어 입력함. 검색 기준 칩 사용(제목/내용/작성자). 최근 검색어 목록 띄움. 최근 검색어 개별 삭제·전체 삭제.

- **연결 화면** — 검색 결과
- **필요 데이터** — 최근 검색어

### 검색결과-제목/내용

검색 기준 칩 표시(제목 또는 내용 선택됨). 피드 카드 목록 띄움(작성자·시간·타입·썸네일·좋아요·댓글). 검색어 하이라이트 표시(제목 검색=제목에, 내용 검색=본문에). 결과 없으면 안내 문구. 카드 누르면 피드 상세로.

- **연결 화면** — 피드 상세
- **필요 데이터** — 검색어, 검색기준, 피드 결과 목록

### 검색결과-작성자

검색 기준 칩 표시(작성자 선택됨). 사용자 리스트 띄움(프로필·닉네임(하이라이트)·작성글 수). "보기" 버튼. 결과 없으면 안내 문구. 누르면 사용자 상세로.

- **연결 화면** — 사용자 상세
- **필요 데이터** — 검색어, 사용자 결과 목록(닉네임, 프로필, 작성글 수)

### 사용자 상세

프로필 사진·닉네임 띄움. 채팅 걸기 버튼·차단 버튼 사용. 작성 글 탭 띄움(그 사용자 피드 목록). 작성 댓글 탭 띄움(그 사용자 댓글·대댓글 목록). 본인 프로필이면 채팅/차단 숨김.

- **연결 화면** — 채팅방, 피드 상세
- **필요 데이터** — 사용자 정보(닉네임, 프로필 사진), 작성 글 목록, 작성 댓글 목록

### 신고

신고 사유 목록 띄움(스팸/욕설·비방/음란물/허위정보/기타). 사유 선택함. 기타 선택 시 상세 사유 입력함. 신고 버튼·취소 버튼. 신고 완료 안내 띄움.

- **연결 화면** — 없음 (팝업 닫고 원래 화면 복귀)
- **필요 데이터** — 신고대상 유형(피드/댓글), 신고대상ID, 신고자ID, 신고사유, 상세사유

## 채팅

### 채팅방목록

내가 참여한 채팅방 목록 띄움. 각 방에 상대 프로필·닉네임·최근 메시지·최근 시간·안읽음 개수 표시. 최근 대화순 정렬. 방 누르면 대화방으로 이동. 채팅방 없으면 안내 문구 띄움.

- **연결 화면** — 채팅방(대화)
- **필요 데이터** — 채팅방 목록(채팅방ID, 상대 닉네임·프로필, 최근 메시지, 최근 시간, 안읽음 수)

### 대화방

상단에 상대 닉네임 표시. 메시지 목록 띄움(내 메시지 우측, 상대 메시지 좌측). 메시지에 시간·읽음 표시. 메시지 입력창·전송 버튼. 사진 전송(선택). 뒤로가기. 상대 닉네임 누르면 프로필로 이동.

- **연결 화면** — 채팅방 목록, 사용자 상세
- **필요 데이터** — 채팅방ID, 메시지 목록(보낸사람, 내용, 시간, 읽음여부), 상대 정보

## 마이페이지

### 북마크

북마크한 카페 목록 띄움. 북마크 해제 가능. 누르면 해당 카페 상세로 이동. 없으면 안내 문구.

- **연결 화면** — 카페 상세
- **필요 데이터** — 카페 목록

### 내 정보 수정

프로필 사진 변경함. 닉네임 수정함(중복 확인). 비밀번호 변경(현재·새 비밀번호 입력). 저장 버튼.

- **연결 화면** — 마이페이지 메인
- **필요 데이터** — 닉네임, 프로필 사진, 현재 비밀번호, 새 비밀번호

### 내가 쓴 피드

내가 작성한 피드 목록 띄움(미니카드, 타입·시간·좋아요·댓글). 누르면 피드 상세로 이동. 글 없으면 안내 문구.

- **연결 화면** — 피드 상세
- **필요 데이터** — 내 피드 목록

### 차단 목록

차단한 사용자 목록 띄움(프로필·닉네임). 차단 해제 버튼. 없으면 안내 문구.

- **연결 화면** — 없음
- **필요 데이터** — 차단 목록(사용자ID, 닉네임, 프로필)

### 내가 쓴 댓글

내가 작성한 댓글·대댓글 목록 띄움(댓글 내용·원본 피드 정보·시간). 누르면 해당 피드 상세로 이동. 없으면 안내 문구.

- **연결 화면** — 피드 상세
- **필요 데이터** — 내 댓글 목록(댓글 내용, 원본 피드ID, 시간)

### 리뷰 단 카페

내가 리뷰를 작성한 카페 목록 띄움(카페명·내 평가·작성시간). 리뷰 수정·삭제 가능. 누르면 카페 상세로 이동. 없으면 안내 문구.

- **연결 화면** — 카페 상세, 리뷰 수정
- **필요 데이터** — 내 리뷰 목록(카페명, 내 평가, 시간)

### 메인

내 프로필 사진·닉네임 표시. 메뉴 목록 띄움(내 정보 수정, 내가 쓴 피드, 내가 쓴 댓글, 북마크, 리뷰 단 카페, 로그아웃, 회원 탈퇴). 각 메뉴 누르면 해당 화면으로 이동.

- **연결 화면** — 내 정보 수정, 내가 쓴 피드, 내가 쓴 댓글, 북마크, 리뷰 단 카페, 로그인(로그아웃 시)
- **필요 데이터** — 내 정보(닉네임, 프로필 사진)

## 계정

### 로그인

이메일, 비밀번호로 로그인함. 소셜로그인(카카오,구글) 지원. 자동 로그인 체크박스 사용. 회원가입 문구 띄움. 아이디/비밀번호 찾기 문구 띄움

- **연결 화면** — 회원가입-약관동의, 비밀번호 찾기, 홈
- **필요 데이터** — 이메일, 비밀번호

### 회원가입-약관동의

이용약관, 개인정보 처리방침 목록 띄움. 전체 동의 체크박스 사용. 항목별 개별 동의 체크 가능. 필수/선택 약관 구분 표시. 다음 버튼(필수 동의 시 활성화).

- **연결 화면** — 회원가입-기본정보
- **필요 데이터** — 약관 동의 여부

### 회원가입-기본정보

이메일 입력함. 이메일 중복 확인 버튼 사용. 비밀번호 입력함. 비밀번호 확인 재입력함. 비밀번호 일치/형식 안내 문구 띄움. 다음 버튼.

- **연결 화면** — 회원가입-이메일인증
- **필요 데이터** — 이메일, 비밀번호, 비밀번호 확인

### 회원가입-이메일인증

가입 이메일로 인증코드 발송함. 인증코드 입력함. 유효시간 타이머 띄움. 재전송 버튼 사용. 인증 확인 버튼.

- **연결 화면** — 회원가입-프로필설정
- **필요 데이터** — 인증코드

### 회원가입-프로필설정

닉네임 입력함. 닉네임 중복 확인 버튼 사용. 프로필 사진 등록함(미등록 시 기본 이미지). 가입 완료 버튼.

- **연결 화면** — 회원가입-완료
- **필요 데이터** — 닉네임, 프로필 사진

### 회원가입-완료

가입 완료 안내 문구·이미지 띄움. 환영 메시지 띄움(닉네임 표시). 로그인하기 버튼.

- **연결 화면** — 로그인
- **필요 데이터** — 없음

### 비밀번호 찾기

가입한 이메일 입력함. 인증코드 발송 버튼 사용. 가입되지 않은 이메일 시 안내 문구 띄움.

- **연결 화면** — 비밀번호 재설정
- **필요 데이터** — 이메일

### 비밀번호 재설정

인증코드 입력·확인함. 새 비밀번호 입력함. 새 비밀번호 확인 재입력함. 비밀번호 형식 안내 문구 띄움. 변경 완료 버튼.

- **연결 화면** — 로그인
- **필요 데이터** — 인증코드, 새 비밀번호, 비밀번호 확인

## 관리자

### 관리자 메인

관리 메뉴 목록(신고 관리, 유저 관리) 표시. 각 메뉴 누르면 해당 화면 이동. 관리자만 접근 가능.

- **연결 화면** — 신고 목록, 유저 관리
- **필요 데이터** — 없음

### 신고 목록

접수된 신고 목록 표시(대상유형, 사유, 상태, 신고 시간). 상태별(대기/처리완료/반려) 필터. 누르면 신고 상세로 이동. 없으면 안내 문구.

- **연결 화면** — 신고 상세, 관리자 메인
- **필요 데이터** — 신고 목록(신고ID, 대상유형, 대상ID, 사유, 상태, 신고자, 시간)

### 신고 상세

신고 상세 정보 표시(대상 콘텐츠 내용, 사유, 상세사유, 신고자). 버튼: 처리완료 / 반려 / 대상 콘텐츠 숨김 / 작성자 정지.

- **연결 화면** — 신고 목록
- **필요 데이터** — 신고 상세, 대상 콘텐츠(피드 or 댓글), 작성자 정보

### 유저 관리

유저 목록·검색. 각 유저 정지 / 정지 해제 버튼. 정지 상태 표시.

- **연결 화면** — 관리자 메인, 유저 상세
- **필요 데이터** — 유저 목록(닉네임, 이메일, 상태)
